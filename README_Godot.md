# NeuroCheat 3D — Godot 4 專案版 (`生醫godot`)

這是專為 **Godot 4** 打造的 **NeuroCheat: Don’t Get Caught (3D 教室版)** 完整專案。

## 🚀 如何啟動遊戲

### 方法一：一鍵直接遊玩
雙擊資料夾內的 **`run_godot_game.bat`**，即可直接透過您電腦中的 Godot 4 啟動 3D 遊戲視窗！

### 方法二：從 Godot 4 編輯器開啟（可自由修改 3D 場景與程式碼）
1. 打開您的 **Godot 4**（位於 `C:\Users\ACER\Downloads\Godot_v4.7.2-stable_win64.exe`）。
2. 在專案管理員點擊 **「匯入 (Import)」**。
3. 選擇本資料夾 `C:\Users\ACER\Downloads\生醫godot\project.godot`。
4. 進入編輯器後，按下右上角的 **「執行專案 (Play / F5)」** 即可開始遊玩！

## 🎮 遊戲功能與 3D 互動操作

1. **雙模式切換**：
   - **`[1]` 手動調控模式 (Manual Bio-Control)**：可用鍵盤自由調控 ECG 心率、EEG 腦波與 EMG 肌電抽屜。
   - **`[2]` 外部訊號輸入模式 (External Bio-Input)**：鎖定鍵盤的 ECG/EEG 控制，透過內建 `PacketPeerUDP` 監聽 `127.0.0.1:5005` 的即時生理訊號（可搭配同資料夾下的 `python external_signal_sender.py` 或 Arduino 感測器發送）。
2. **滑鼠第一人稱 3D 視角**：
   - 坐在木製書桌前，移動滑鼠即可 360° 觀察講台上的**奶龍教授 (Nailong)**、**左右鄰座同學**，或低頭查看**桌面上的考卷**與**桌下抽屜**。
   - 按 **`[Tab]`** 可切換「鎖定滑鼠轉視角」與「顯示滑鼠游標點擊介面」。
3. **3D 桌面考卷平面投影 (`SubViewport` + `QuadMesh` + 3D Raycast)**：
   - 考卷完全平貼在 3D 書桌平面上，支援自動換行不截斷。
   - 將畫面中央準星對準考卷上的 A / B / C / D 選項點擊左鍵（或直接按鍵盤 **`1` / `2` / `3` / `4`**）即可作答。
4. **3D 抽屜小抄與伸手動畫**：
   - 按住 **`[Space 空白鍵]`** 或 **`[滑鼠右鍵]`**（觸發 EMG 肌電訊號），書桌下方的 3D 抽屜會向前滑開，並伸出 3D 雙手打開抽屜內的黃色小抄！
   - 放開按鍵後，雙手會收回並推回抽屜。
5. **生理訊號控制（模式 1 手動模式）**：
   - **ECG 心率 (BPM)**：**`↑` / `↓` 方向鍵**（或 `Q` / `E`）調整心率。按住空白鍵開抽屜時心率會自然上升；若奶龍轉頭時 `BPM > 100` 會被抓包！
   - **EEG 腦波專注度 (%)**：**`←` / `→` 方向鍵**（或 `Z` / `C`）調整 Alpha/Beta 專注度。維持在 **`> 65%`** 且抽屜拉開時，即可破譯小抄上的正確答案！
